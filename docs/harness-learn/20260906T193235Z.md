## Root cause

**Miner bug (code fix).** `scripts/harness-learn.mjs` `mineTrace` built retry
details with `${d.reason ?? d.error ?? ""}`. Because `??` only falls through on
`null`/`undefined`, a trace event carrying `reason: ""` masked its `error`
field, so every context-free `subagent_retry`/`retry` collapsed into opaque
lessons whose whole detail was `attempt=?` (fingerprints `3a1cdfd1e6d7c64b`,
`8ed7726bc614f5c8`; evidence: `attempt=?`, 4x). The fixer agent had nothing
actionable to work with.

**Instruction gap (prompt fix).** The read_file/edit_file cluster — the largest
block of signals (18 of 41) — originates in tools owned by the graff harness,
not by this repo, so their validation cannot be changed here. But the loop that
keeps regenerating these lessons is this repo's `scripts/harness-selflearn.sh`,
and its fixer prompt carried no recovery guidance: agents repeated identical
failing `read_file contains` calls (12x empty `contains`, 2x `contains` combined
with line ranges), retried identical `bash` calls, and re-issued edit spans after
a partial batch had already applied. Evidence quoted from the report:
`contains must not be empty` (12), `same call repeated 4x` (read_file),
`edit span 2/2 failed: old_string not found ... (1 earlier span(s) DID apply)`,
`2/4 todos unfinished`.

## Changes

1. `scripts/harness-learn.mjs` — `mineTrace` now uses `d.reason || d.error` (detail and fingerprint input), so an empty-string reason no longer hides the event's error, and the attempt number is preserved. Future retry lessons carry real context (e.g. `api error: ... attempt=2`).
2. `scripts/harness-selflearn.sh` — added a "Tool-usage recovery notes" block to the fixer prompt: non-empty `contains` never combined with line ranges; re-read after a partially applied batched edit; never repeat an identical failing call; use codedb instead of `cat`/`grep`; close or cancel todos before finishing.
3. `tests/harness-learn.test.ts` (new) — regression test: runs the miner against a fixture trace with `reason:""` + an `error` and asserts the lesson surfaces the error text, the attempt number, and distinct fingerprints; added to `tsconfig.tests.json` include.

## Deliberately not done

- No changes to `apps/agent/` tool wrappers, `actor.ts` instruction strings, capability-builder, channel-response or automations: no mined lesson implicates them (all tool_error receipts reference graff-harness tools or one-off operator commands).
- No retry-loop detector tuning in the miner: flags like "same call repeated 2x" may include legitimate re-reads, but tightening it without access to `.graff` transcripts (excluded by guardrail) risks discarding real signals.
- No handling for provider credit-exhaustion retries (`7a5a36413e6f1de3`) — quota is environmental.
