Security decisions

  • Provider keys remain host-side. The existing ThinkFeel file is 0600 and its directory is 0700; operator initialization uses a separate private file.
  • GLM selects bounded read tools. ThinkFeel has no tools, credential access, execution or approval authority. It receives a neutral phrase, never the factual receipt.
  • Accepted wording is durable before delivery. Telegram unknown outcomes are surfaced rather than retried. This deliberately does not promise exactly-once delivery.
  • One host owns a state directory. Private Telegram sender verification and the invite allowlist determine tenancy; request bodies cannot choose another user.
  • Native actor transcripts are private SQLite files, not encrypted custody records. Best-effort text redaction does not make arbitrary conversation safe for secrets.
