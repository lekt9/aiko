What changed

  • Home now opens the login list, with search, favorites and a familiar detail panel.
  • My vault and agent profiles live in one dropdown. Switching the view does not change permissions.
  • Add a login, share an existing one, or create a profile with selected logins. Sharing does not duplicate credentials.
  • Available to controls standing access. Remove from profile and Delete login are different, confirmed actions.
  • No overview metrics, session pages, revision counters, maintenance controls or activity/developer navigation. Only actionable sign-in or manager-reconnect exceptions remain.
  • Imports and connected-manager samples are in Settings. Optional SDK guidance is collapsed.

Whole-file CSV import

Settings → Import CSV accepts up to 1,000 rows / 1 MiB per file. Common column names are matched automatically; custom mappings are available. Every row appears in a paginated preview. Duplicate website/username pairs and invalid/non-login records are reported explicitly; different accounts on the same website are retained. Nothing is silently truncated or overwritten.

Importing creates independent demo records in My vault, without granting agent access. Recognized password/note/token columns are discarded locally; only mapped fictional metadata is sent. Real domains are rejected. CSV items display Password: Not imported in this demo. The server revalidates every row and publishes the batch only after capacity checks. Request bodies are bounded while streaming.

Web-preview scope

The separately implemented encrypted backend and new SDK have their own evidence report. This report covers the unchanged synthetic web protocol, not production custody.

Deliberate limits of this web demo

  • The password is a fixed fake value. Add/edit forms cannot ingest or update a real password.
  • There is no owner authentication, vault cryptography, tenant isolation, production OAuth issuer or real password-manager authorization.
  • Sign-in and source reconnect are simulations. The separate backend has a private CDP adapter and renewal worker, but they are not connected to this demo. Provider-specific browser recipes remain gated.
  • Session machinery is hidden from the UI, not newly implemented as an autonomous service.
  • Access removal blocks future retrieval/sync; already-delivered cookies may still work at the destination.
  • State is shared process-local memory. Tests and server restarts reset it. No credentials or UI profile state are written to localStorage.
  • Axe is not complete accessibility certification. Safari, Firefox, screen readers and real touch hardware are unverified.
