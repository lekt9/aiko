Build and regression gates

Frozen-lockfile installation, scoped protocol/SDK/backend/web and backend-test typechecks, formatting, backend/SDK/web production builds, and all 127 tests passed with no skipped tests in the recorded run. The final workspace-wide typecheck is separately blocked by a concurrently created apps/agent scaffold with no source inputs (TS18003); that unrelated work was not edited. Its failure is retained in typecheck.log, while the passing scoped checks are in typecheck-owned.log. The original UI additionally passed 40 production browser checks, 10 + 10 real HTTP checks across development/production, and 20 axe scans with zero violations. No personal Chrome profile was used.

Two multi-I/O tests initially exceeded their five-second test budgets during heavy host memory/CPU contention. The final run bounds Vitest concurrency to two workers and gives the two full-flow integration cases twenty seconds, without changing their assertions or production deadlines. SDK package-consumer verification also required selecting pnpm 10 rather than the host's global pnpm 11; the final tarball imports passed.

Important issues caught and fixed during implementation: OAuth mount-prefix handling, normalization of single versus multiple Set-Cookie headers, stale-worker publication, refresh/code replay, private-parent conflicts, preserving tool results after sync failure, fail-closed browser recovery, and an outdated test-only Undici version. The final lockfile audit reports zero known advisories; this does not establish supply-chain or application security.

What is not claimed

  • The current TanStack UI is not wired to real custody. Its CSV dialog still discards passwords. Use only fictional data in that preview.
  • No live owner IdP, 1Password account or AWS KMS integration was exercised. Those require operator authorization and environment-specific testing.
  • Only the configurable fixed-origin JSON/form recipe is shipped. Provider-specific browser/Google SSO, MFA, CAPTCHA, passkeys and device-bound sessions require reviewed implementations. Unsupported flows challenge instead of pretending success.
  • Runtime affinity is fail-closed, not a cross-host browser dispatcher. The MCP helper needs the host's maintained, authenticated transport; no standalone MCP server is bundled.
  • Module boundaries are not an OS sandbox. A model must not receive unrestricted access to the credential-owning process, files, raw CDP or secret-bearing APIs.
  • Revocation cannot retract cookies already delivered or guarantee upstream logout. Fencing prevents stale database publication, not cancellation of already-sent provider requests.
  • Production load, edge policy, logging/IAM, real disaster recovery and independent security review remain activation gates. Firefox, Safari, screen readers and real touch hardware are not certified by these checks.
