# Code of Conduct

This project follows a short, enforceable conduct rule:

**Be respectful. No harassment, hate, or personal attacks.**

## Expected

- Assume good faith in technical disagreement
- Critique code and claims, not people
- Do not publish others' private data or customer operational material

## Unacceptable

- Harassment, threats, or discriminatory abuse
- Doxxing or posting private credentials
- Opening public issues that are actually security reports (use [`SECURITY.md`](SECURITY.md))

## Enforcement

Maintainers may warn, hide, or refuse contributions that break this policy.
Reports can go through the same private channel as [`SECURITY.md`](SECURITY.md)
when the incident itself is sensitive.

This is not a comprehensive legal policy; it is the minimum bar for
participating in the public repository.
