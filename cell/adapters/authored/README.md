# Authored adapters

`author.py` is the native, bounded authoring membrane. It selects a new adapter
family from a promoted boundary's pinned response shape, writes the package
inert, proves behavior through the existing Unbrowse port, admits the exact
bytes by digest, attaches only the declared origin/opaque handle/`observe`
authority, retries that same real path, and emits an independent judgment.

The transform catalogue cannot inspect gap acceptance. `audit-catalog` enforces
that source-level falsifier. `compile` deliberately creates no registry or
attachment: compilation is never retention.
