# Aiko 0.2.103

Aiko’s durable agent harness now treats Contract as a universal membrane:
meaningful decisions, effects, dependencies, and observed outcomes cross typed
Contract boundaries while ordinary computation stays native.

Highlights:

- Native multiscale action → sensor → evaluator system compilation.
- Effect-derived photon/positron evidence and fail-closed settlement checks.
- Contract chokepoint coverage across tool and interface routes.
- Persistent prediction witnesses and signed evaluation lineage.
- Provider-neutral process, messaging, CLI, TUI, MCP, and mobile interface
  envelopes.

The release’s structural and behavioral gates pass. ARC-AGI-3 remains an honest
mixed result: the stored all-games run tied at 14 levels and saved four
completion actions, but its 600-second replay witness timed out during release
evaluation and is not claimed as a currently reproduced win.
