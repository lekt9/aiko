# archive/ — process history, kept out of the living tree

Everything under this directory is **historical**: it records how work was
planned and tracked, not what the tree is today. Nothing here is a worklist,
an inventory, or an authority — for those, start at
[`docs/SOURCE-OF-TRUTH.md`](../docs/SOURCE-OF-TRUTH.md).

| Entry | What it was |
|---|---|
| `plans/PLAN.md` | pre-monorepo on-chain commons plan |
| `plans/PLAN-aiko-convergence.md` | the T1–T4 convergence plan — all four landed; kept for the reasoning |
| `smithers-tickets/` | the `aiko-flow/.smithers/tickets` work-ticket history (the path convention is still live; these are the closed artifacts) |
| `aiko-flow-audit/` | point-in-time audit reports that drove past burndowns |

Files here are never cited as current behaviour. If a claim in one of these
documents matters today, it must be re-established against the living tree and
its gates — a historical plan saying something worked is not evidence that it
works now.
