## FAQ (pre-written for each gig)

**"What if the site blocks scraping?"**
I handle rate limiting, rotating user agents, and anti-bot measures. If a site is actively hostile, I'll tell you before starting and suggest alternatives.

**"Do you provide the source code?"**
Yes — every delivery includes all source code, a README, and instructions for running and modifying it yourself.

**"What if the output isn't 100% accurate?"**
I build validation layers that flag suspicious records. For large jobs I include a validation report showing extraction accuracy. You only pay full price for verified output.
